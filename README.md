# People Counting Using Edge, Cloud, and Edge–Cloud Computing
Course: 2110415 Software-Defined System
Instructor: Assoc.Prof. Kultida Rojviboonchai

## Overview
In this activity, students will explore and compare the performance of three computing architectures: Edge, Cloud, and Edge–Cloud computing, using a people-counting application. The application uses YOLOv8, a state-of-the-art object detection model, to detect and count people in images uploaded from students’ computers.
